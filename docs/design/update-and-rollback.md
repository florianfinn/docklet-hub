# Updates, Rollback und Sicherungen

Updates werden ausdrücklich angefordert. Ergebnisprüfung und Fristen werden vor Umsetzung entschieden. Beim Fehlschlag ist das vorherige Image mit der vorherigen Definition der Standard-Rückweg. Optional wird eine Nutzerdatensicherung angeboten.

Dateisicherung allein garantiert keine Anwendungskonsistenz. Sicherungsumfang, Ruhephase und Wiederherstellung brauchen einen eigenen Vertrag. Datenwiederherstellung ist getrennt von Image-Rollback. Agenten-Updates erfolgen über den Watcher mit festgelegter Mindestversion und Signaturidentität.
