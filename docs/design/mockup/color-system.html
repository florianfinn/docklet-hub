Farbsystem

Jedes Modul hat eine eigene Palette, und jede Palette hängt an genau einer Zahl: dem Farbton. Alles andere — Kennfarbe, Symbolplatte, Fokusring, die fünf Diagrammfarben — wird daraus gerechnet. Eine Palette zu tauschen heißt später, eine Zahl zu ändern.

Ein Modul setzt eine Zahl
/* das ist alles, was ein Modul definiert */
[data-modul="plex"]       { --h: 62; }
[data-modul="verwaltung"] { --h: 265; --c: 0.022; }
[data-modul="statistik"]  { --h: 195; }
[data-modul="teamspeak"]  { --h: 255; }
[data-modul="container"]  { --h: 300; }
[data-modul="spiele"]     { --h: 350; }

Warum Modul- und Zustandsfarben sich nicht in die Quere kommen
Sie haben getrennte Rollen. Modulfarben tragen Flächen — Symbolplatten, Diagramme, Kennzahlen, den Fokusring. Zustandsfarben erscheinen nur als Punkt, dünner Balken oder kurze Beschriftung, immer mit Symbol — nie als Fläche. Deshalb liest sich ein oranger Plex-Balken nie als Warnung, obwohl Orange und Bernstein benachbart sind.
Später per Klick tauschbar
Weil ein Modul nur den Farbton setzt, ist ein Palettenwechsel ein Zahlenfeld in den Website-Einstellungen — kein Neusatz von zwölf Tokens. Der Farbwähler, den die Zielabfolge ohnehin durch geprüfte Vorgaben ersetzen will, wird damit ein Farbtonregler je Modul.
Kontrast ist eingebaut, nicht geprüft
Alle Kennfarben liegen auf derselben Helligkeit (0.78) und Buntheit (0.145). Wer den Farbton dreht, kann den Kontrast nicht kaputt machen — das war beim freien Farbwähler die Falle.
Hell und dunkel
Im hellen Thema wandert die Kennfarbe auf 0.55 Helligkeit, der Farbton bleibt gleich. Ein Modul behält seine Identität in beiden Fassungen.
