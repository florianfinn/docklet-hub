Design-Etappe D0 · docklet-hub#62

Stacks zuerst, Container auf Zuruf

Die Übersicht führt jetzt Stacks; ein toter oder kranker Container färbt seinen ganzen Stack. Alle Container einzeln stehen eine Ebene tiefer, die Container eines Stacks auf dessen eigener Seite. Farben sind nach Aufgabe gestaffelt — Host am kräftigsten, eigene Marken leiser, Bereich nur angedeutet. Die drei Schalter sind im Hub keine globalen Regler, sondern Einstellungen je Host und je Marke.
