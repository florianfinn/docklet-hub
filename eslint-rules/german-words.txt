# Format: ein Wort je Zeile, kleingeschrieben. Verglichen wird gegen die
# einzelnen Wörter eines Bezeichners, nachdem camelCase, PascalCase,
# CONSTANT_CASE und snake_case zerlegt wurden. Zeilen mit # sind Kommentar.

# ══ DIE AUFNAHMEPRÜFUNG ════════════════════════════════════════════════════
#
# Die Frage lautet NICHT „trifft dieses Wort heute einen englischen Namen?",
# sondern:
#
#     KANN DIESES WORT IN ENGLISCHEM CODE ALS EIGENES WORT AUFTRETEN?
#
# ⚠️ Der Unterschied ist der ganze Punkt. Diese Regel wirkt auf Code, den es
# noch nicht gibt. Ein Bestandstreffer rechtfertigt gar nichts: der Bestand
# steht in jedem der drei Repos ohnehin auf einer Ausnahmeliste (Stand
# 2026-09-04: Hub 0, Agent 0, Dashboard 257 Namen), sonst wäre jede Datei sofort rot. Ein Wort, dessen
# einzige Rechtfertigung Bestandstreffer sind, schützt also NICHTS und trägt
# das volle Fehlalarmrisiko. `fallBack`, `standAlone`, `grossAmount`,
# `holeSize`, `fundId`, `basisPoints` schreibt jeder irgendwann — und eine
# Regel mit Fehlalarmen wird abgeschaltet, nicht befolgt.
#
# Die Beweislast liegt bei dem, der ein Wort AUFNIMMT. Wo eine frühere Fassung
# dieser Liste ein Wort ausgeschlossen hat, bleibt es draußen, solange das
# Gegenargument nur ein Bestandstreffer ist.
#
# So wird geprüft, in dieser Reihenfolge:
#   1. Ist das Wort im Englischen dasselbe Wort oder ein englisches Wort mit
#      anderer Bedeutung? Dann raus, mit englischem Gegenbeleg unten.
#   2. Messung gegen einen englischen Korpus: die Typdeklarationen der
#      Abhängigkeiten (3239 .d.ts-Dateien, 572021 Bezeichner-Knoten, fremder
#      englischer Code). Von den 342 Kandidaten trafen dort genau zwei:
#      `basis` (flexBasis) und `fall` (fallThrough). Beide sind raus.
#      ⚠️ Der Korpus BEWEIST nur Vorkommen, nie Abwesenheit — `grossAmount`
#      steht dort nicht und ist trotzdem selbstverständliches Englisch.
#      Schritt 1 bleibt deshalb das schärfere Sieb.
#   3. Messung gegen die drei eigenen Bäume. Ein Treffer auf einem englischen
#      Namen ist ein Ausschlussgrund — kein Treffer ist KEIN Aufnahmegrund.
#
